# 平台管理后台 · 管理员操作说明

> 适用对象：平台运营 / 客服 / 财务 / 风控人员
> 访问地址：`http://<服务器地址>:4173/admin` ｜ 初始账号见部署文档
> 编号对应《需求说明书》4.5 节，便于对照验收。

---

## 0. 登录与界面

1. 浏览器（Chrome / Edge）打开 `/admin`，输入手机号 + 密码登录（初始口令见部署文档，登录后请立即在「系统设置」修改）。
2. 左侧为功能导航，按 **总览 / 用户 / 交易 / 规则 / 资金 / 风控 / 运营 / 系统** 八组排列；有提醒的菜单会显示红色数字角标（待审教员、待处理退款、待审提现、风控与客诉）。
3. 顶部栏显示当前管理员，并提供「刷新数据」与「手动触发结算」。
4. 所有列表支持横向滚动；所有危险操作（禁用、关闭订单、驳回、仲裁）都会弹二次确认。

**没有回退按钮的操作请务必先确认对象**：删除、封禁、驳回、关闭订单均不可自助撤销。

## 1. 数据总览（4.5.1）

进入 `/admin` 即为总览页。

| 区域 | 能做什么 |
| --- | --- |
| KPI 卡片 | 查看总用户、日活、今日订单、本月 GMV、平台营收、担保在账 |
| 区域业绩排行 | 比较各片区订单量与 GMV，判断是否需要补充地推资源 |
| 供需热力 | 对比片区「在册教员」与「在招需求」，供不应求的片区优先拓展教员 |
| 14 天趋势 | 切换订单量 / GMV 口径，观察增长与波动 |
| 待办清单 | 一键跳转到待处理事项（教员审核、提现、退款、申诉、风控、客诉） |
| 手动触发结算 | 立即执行 T+N 到期放款（正常情况无需手动，系统每分钟自动执行） |

## 2. 用户管理（4.5.2）

### 2.1 查询与启停用
`用户管理` → 选择角色 / 状态 / 关键字（昵称或手机号）→ 查询。
- 列表按角色显示附加信息：教员（审核状态、等级、成长分、评分、在线状态）、家长（信用分、信用等级）、业务员（工号）、代理（等级、分成）。
- 操作列「禁用 / 启用」：**禁用后该账号所有接口立即返回 403**，不能登录也不能下单接单。禁用需填写原因，会写入操作日志。

### 2.2 教员资质审核
`教员资质审核` → 默认显示待审与已驳回。
1. 核对真实姓名、身份证（脱敏展示）、身份类型、科目学段、课时单价、证件图片。
2. 通过：点「通过」，账号立即获得接单资格并收到站内通知。
3. 驳回：点「驳回」并**必须填写原因**，教员端会显示原因并允许修改后重新提交。

> 平台红线：资质审核权仅归平台，区域代理只能推荐、不能审核。

### 2.3 教员等级调整
`教员等级调整` → 搜索教员 → 选择目标等级并填写备注。
- 调整会把成长分量置为该等级下限，并写入 `level_logs`。
- 等级直接决定抽佣比例与派单权重，调整前请确认是否已与运营负责人确认。

## 3. 区域与代理（4.5.5）

`区域与代理` 页分三块：

### 3.1 片区与电子围栏
- 填片区名称、编码、中心经纬度、服务半径，点「按中心生成」自动生成 4 点矩形围栏（也可手填 `[[lat,lng],...]` JSON 画多边形）。
- 围栏决定：家长自然注册的片区归属、跨区订单的收益归属。

### 3.2 代理签约
填姓名、手机号、片区、等级、保证金、服务费分成、管理提成 → 创建。系统会返回**初始密码**，请转交代理本人并提醒首次登录后修改。

### 3.3 代理日常管理（列表右侧按钮）
| 按钮 | 作用 |
| --- | --- |
| 详情 | 查看档案 + 保证金台账 + 考核完成度（本月 GMV / 订单量 / 活跃业务员进度条） |
| 编辑 | 修改片区、等级、服务费分成、管理提成（比例必须在 0~1 之间） |
| 保证金 | 缴纳 / 退还保证金，逐笔记入台账，退款不得超过当前余额 |
| 禁用 / 启用 | 禁用后代理端全部接口 403，其名下业务员失去片区归属 |

> 考核指标（月度 GMV / 订单量 / 活跃业务员 / 达标线）在「规则配置中心 → 代理考核指标」统一调整。

## 4. 订单与需求（4.5.3）

### 4.1 订单管理
按状态、片区、订单号筛选；列表含实付、平台服务费、教员实收。
- **详情**：查看完整订单（含分账明细、打卡记录、时间轴）。
- **改价**：仅对**未支付**订单生效，改价会写入订单备注与操作日志。
- **关闭订单**：需填写原因，会通知家长与教员，订单变为已取消且不可恢复。已支付订单请改用退款流程。
- **导出订单**：按当前筛选条件导出 CSV（含片区、五项分账金额、中文状态），可直接用 Excel 打开对账。

### 4.2 需求池
展示家长发布中的需求与报名情况。
- **清理超时报名**：立即执行一次「超时未确认报名失效」（阈值见规则配置 `grab_confirm_timeout_hours`，默认 24 小时）。系统每分钟也会自动执行，此按钮用于临时需要立刻清理时。

## 5. 退款工单（4.5.3）

家长在订单页发起退款后，订单进入「退款中」并生成工单。

1. `退款工单` → 找到目标订单，核对退款原因与订单履约记录（是否已打卡、是否已上课）。
2. **同意退款**：按订单实付金额原路退回，写入支付流水，订单变为「已退款」，同时通知家长与教员。
3. **驳回**：必须填写原因，订单恢复为「待上课」并通知家长。

> 开课前 4 小时外取消属免费取消，系统会自动全额退款，无需人工介入；4 小时内取消会自动扣 20% 违约金并赔付教员。

## 6. 规则配置中心（4.5.4）

**这是全平台最敏感的一页**：所有数值改完立即生效，不需要重启服务。

操作方式：左侧选择规则分组 → 表单直接改（数组型渲染为表格可增删行，对象型逐字段，嵌套数组为子表格）→ 点保存 → 顶部提示「已热更新生效」。

| 分组 | 关键项 | 改动影响 |
| --- | --- | --- |
| 派单匹配规则 | 最大接单半径、抢单超时、距离系数下限、加急加权 | 影响订单推送给哪些教员、优先级排序 |
| 上门打卡定位阈值 | `max_distance_m` | 超过即拦截打卡并生成风控事件 |
| 加急费配置 | 金额 | 家长发布加急需求时的额外收费 |
| 教员等级规则 | 等级区间、抽佣比例、派单权重 | 直接影响教员收入与曝光 |
| 教员成长规则 | 课时加分、好差评基数、违规扣分 | 影响升降级速度 |
| 家长信用规则 | 信用区间、评价权重、加减分项 | 影响评价对教员成长分的权重 |
| 评价计分规则 | 好差评阈值、评价时效、预设标签 | 影响评价页可选标签与有效期 |
| 业务员奖励方案 | 注册奖、留资奖、阶梯提成、日/周冠军奖 | 直接影响推广成本 |
| 代理分成规则 | 服务费分成比例、管理提成比例、账单日 | 直接影响代理收益 |
| 代理考核指标 | 月度 GMV / 订单 / 活跃业务员目标、达标线 | 影响代理首页考核卡片 |
| 结算规则 | 冻结天数、最低提现额、手续费率、免费取消时长、违约金比例 | **改动会影响所有未结算订单的放款与提现** |
| 风控阈值 | 高频取消、同设备/同 IP 注册上限、下单频次 | 影响注册拦截与刷单标记 |
| 通知规则 | 上课提醒提前分钟数、是否启用 | 影响上课提醒推送时机 |
| 基础参数 | 平台名称、城市、合规提示文案 | 显示在各端首页 |

> 修改抽佣、分成、结算类规则前请务必与财务确认；所有变更记录在「系统设置 → 操作日志」中可追溯（含修改前后值）。

## 7. 财务资金（4.5.6）

| 区块 | 操作 |
| --- | --- |
| 资金对账 | 两条恒等式自动校验：①实付 = 教员实收 + 服务费；②服务费 = 代理分成 + 业务员提成 + 平台净收入。显示绿色即平账，出现差额会标红并提示排查方向 |
| 导出对账报表 | 导出汇总 CSV 用于月度财务归档 |
| 发票受理 | 家长提交开票申请后在此显示。**开票**：填写电子发票地址（可留空，仅标记已开票）；**驳回**：必须填写原因，家长可修改后重新申请。两者都会通知家长 |
| 提现审核 | 核对申请人与金额 → 打款后点「确认打款」，系统计入累计提现；驳回则金额自动退回用户余额。**请务必在真实打款完成后才点确认** |
| 业务员奖励 | 查看待结算奖励，「批量结算」一次性入账到业务员钱包（正常按周结） |
| 担保资金台账 | 逐笔记录担保账户入账/出账与余额，任意时刻余额应等于「已支付未结算未退款」订单金额之和 |
| 支付流水 | 全部支付与退款流水，含交易号 |

## 8. 风控与审核（4.5.7）

三个页签：

### 8.1 异常订单
来源：打卡定位超阈值、虚假打卡、批量注册、高频下单刷单等。
| 操作 | 用途 |
| --- | --- |
| 关闭 | 确认为误报，解除结算冻结 |
| 冻结结算 | 保持冻结，等待进一步核查（该订单不会被自动放款） |
| 解除冻结 | 只解除资金冻结，事件仍保留 |
| 处罚 | 虚假打卡扣 100 成长分、刷单封禁账号，并通知当事人 |

### 8.2 差评申诉仲裁
教员对差评提交申诉后在此处理。
- **撤销评价**：评价转为隐藏，回滚被扣的成长分并修正评分；
- **维持原判**：记录仲裁结果，评价保留。
仲裁结果会通知教员，且写入操作日志。

### 8.3 投诉工单终审
片区代理未能解决的工单会上报至此。查看沟通记录后填写处理说明并「结案」。

## 9. 运营工具（4.5.8）

四个页签，均支持新增、编辑、删除：

| 页签 | 说明 |
| --- | --- |
| Banner 管理 | 首页轮播。可设排序（越小越靠前）、图片地址、跳转链接；**停用后家长端立即不再展示** |

| 协议文案 | 用户协议、隐私政策、退费规则的正文，保存后家长端立即可见 |

## 10. 系统设置（4.5.9）

- **管理员账号**：查看现有管理员、新增管理员（手机号 + 初始密码）。管理员账号不可被自助禁用或注销。
- **操作日志**：全量操作留痕（操作人、角色、动作、目标、详情 JSON、IP、时间）。
  资金操作、规则变更、权限操作、发票受理均可在此追溯。**纠纷复盘优先查这里。**

## 11. 高频场景速查

| 场景 | 路径 |
| --- | --- |
| 新教员入驻审核 | 用户 → 教员资质审核 → 通过 / 驳回 |
| 家长申请退款 | 交易 → 退款工单 → 核对履约 → 同意 / 驳回 |
| 教员对差评申诉 | 风控 → 差评申诉仲裁 → 撤销 / 维持 |
| 教练提现打款 | 资金 → 提现审核 → 打款后确认 |
| 家长要发票 | 资金 → 发票受理 → 开票填链接 / 驳回填原因 |
| 调整抽佣或分成 | 规则 → 教员等级规则 / 代理分成规则 → 保存（立即生效） |
| 有教员虚假打卡 | 风控 → 异常订单 → 处罚（扣分/封禁） |
| 收到紧急求助 | 风控 → 异常订单（类型「🚨 紧急求助」）→ 电话联系当事人 → 处置后「关闭」；工单含求助定位与上课地址的距离 |
| 月度财务归档 | 资金 → 导出对账报表 + 交易 → 订单导出 |
| 查某人被谁封禁 | 系统 → 操作日志（按动作 `admin.user.toggle` 过滤） |

## 12. 操作红线

1. **资金**：提现审核必须在真实打款之后点确认；担保台账余额不得挪用；对账不平先查规则配置与订单分账字段。
2. **权限**：不得把管理员账号借给代理或业务员使用；管理员取消或注销仅限平台内部执行。
3. **规则**：抽佣、分成、结算、奖励类规则变更前须与财务对齐，变更即生效，影响所有后续订单。
4. **数据**：身份证、手机号、地址属敏感信息，禁止截图外传；导出报表需按公司数据管理规定存放。
5. **合规**：平台定位为家教信息撮合服务，不得为义务教育学科类违规培训导流（首页合规提示文案可在「规则 → 基础参数」维护）。
